更新日期：2026-10-12。此仓库保存 GitHub Pages 可直接运行的静态构建产物。

## 演示内容

- 免费脑健康评估、结果与分享海报、详细报告、添加客服领取 训练计划。
- 每日健脑训练（五款游戏）、训练记录及日报。
- 关联家人、家人管理、查看家人的测评和训练数据。

桌面版左侧「预览工具」可切换已完成评估、训练未开通/已开通、有训练记录等场景。
